# Bundled image credits

All images in this folder are used only as demo/placeholder content for Uzhavan
Direct. Replace them with your own photography before any real deployment.

## `hero-farmer.webp`

Supplied by the project owner (source file
`indian-man-holding-sickle-crops-600nw-498961396.webp`) and used as the login
screen hero. Check the licence of the original stock source before shipping.
